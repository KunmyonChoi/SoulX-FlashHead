업무 비서의 계정 연결

비밀번호는 이 화면에 입력하지 않습니다. Google 로그인은 Google의 화면에서 하고, 여기에는 그 결과로 받은 접근 열쇠만 암호화해 보관합니다. 시험 대화의 가상 고객은 언제나 가짜 Google을 씁니다.

1

서버 소유자 로그인

확인하는 중…

계정을 연결하면 이 서버에 들어오는 사람은 그 계정을 쓸 수 있게 되므로, 먼저 소유자 비밀번호를 정합니다. 서버에서 한 번 실행하세요:

cd v2 && python -m agentkit.auth set-password

2

OAuth 클라이언트 파일 올리기

확인하는 중…

Google Cloud Console에서 Calendar API와 Gmail API를 켜고, 데스크톱 앱 유형의 OAuth 클라이언트를 만든 뒤 내려받은 client_secret_….json을 고르세요. 파일 내용은 암호화해 보관합니다.

3

Google 연결

확인하는 중…

Google 화면에서 계정을 고르고 권한(일정 보기·변경, 메일 읽기·초안·보내기)을 허용합니다. "확인되지 않은 앱" 안내가 나오면 본인이 만든 앱이므로 고급 → 계속을 누르면 됩니다. 이 페이지가 http://localhost 주소로 열려 있어야 합니다.
